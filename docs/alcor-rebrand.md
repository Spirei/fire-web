# Alcor 无损更名

2026-10-01 起产品名为 **Alcor**。页面、邮件、安装名称、分享下载、源码品牌、文档及版本记录使用新名称，不改布局、计算和用户业务数据。

## 已上线兼容合同

| 保留项 | 原因 |
| --- | --- |
| `data/fire.db`、`.fire-encryption-key`、现有数据库表列与迁移标记 | 继续打开同一数据库、解密同一秘密；不能生成空库或新密钥。 |
| `fire_session`、通行密钥／二次验证 Cookie、`fire_prefs`、`fire:*`／`fire.*` 浏览器存储、事件及资源缓存 | 保留登录、配色、字体、字重、排序和已经打开的页面；不会清空或双写一套偏好。 |
| `fire-site-backup`、`fire-ios-backup` 及其字段 | 新旧导出均保持相同协议，旧版本仍可读取；下载文件的展示名称改为 Alcor。 |
| `com.fire.app` Bundle／回调、`fire-ios` client、Keychain、iCloud、UserDefaults 和 `FireLocal` 账本目录 | 更新仍属于同一个已安装 App，继续读取原账本、偏好、授权和云备份。 |
| 已部署域名、GitHub 仓库／GHCR 镜像名、Compose 服务／容器／网络、Watchtower scope、`FIRE_*` 环境变量 | 品牌更名不创建另一个容器或切断更新、授权和持久卷。环境变量和 URL 不用手动迁移。 |
| 旧图片地址、CSS／DOM 内部标识、健康检查的 `service` 字段 | 保持旧资源引用、扩展和运行探针兼容；不是页面展示名称。 |

`lib/brand.ts` 只适配品牌文本设置。已有标题、Logo 文字、App 名称与发件人中的旧品牌自动显示为 Alcor；自定义名称、URL、素材 ID、股票和卡片名称不会被全库替换。通行密钥只适配显示名称，RP ID、origin、revision、凭据和未完成的 challenge 均不变。原数据无需手动 SQL／SSH 修改。

品牌文案中嵌入的完整 URL、无协议域名、邮箱、App 回调和绝对／相对图片路径保持原样；多行文案不合并换行。旧 App 请求及授权列表中的出厂默认设备名 `Fire iOS` 显示为 `Alcor iOS`，但不重写已有授权记录或修改令牌。用户自定义设备昵称（即使含 Fire）保持原样，无需断开重连。

连接服务的可见名称使用 **Alcor Api**。旧品牌设置里的 `Alcor Web`／`Fire Web` 仅在展示层适配；原域名、图片地址、部署名称和授权协议保持不变。

财务独立／提前退休的 **FIRE** 是金融术语，其模块、路由、计算字段及历史说明保持原义。Firefox、含 Fire 的真实证券／卡片名称也不是产品品牌。

仅推送代码不等于已更换线上镜像。沿用现有发布和拉取流程；本次不修改正在运行的群晖容器、数据库或域名。
