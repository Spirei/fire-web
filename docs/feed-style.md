桌面实测：页标题 34px / 40px / 600；动态标题 18px / 26px / 500；正文 16px / 22px / 400；时间 13px / 18px；正文最大宽度 768px；左侧图标 40px、间距 12px。指示弹窗 512px，标题 18px / 26px / 600，说明 16px / 22px，输入 14px / 20px，次操作与主操作均为 36px 高胶囊。手机输入仍为 16px，保留触控命中范围、平板弹窗和短屏适配。

字体使用系统无衬线与中文回退；不下载或分发 Muse 的专有 Optimistic 字体，因此拉丁字形不声称逐像素相同。小人沿用已本地化的原始循环视频，按用户要求放在动态页上方居中。

## 作用域与防回归

- 颜色在 `.feed-theme` 内定义，四类动态弹窗显式携带该类；body portal 不丢失配色。
- 只有 `.tab-panel:not([hidden]) .alcor-feed` 可改变工作区背景。缓存的隐藏动态页不能影响其他页。
- 动态页固定使用这组取色；其余后台仅在用户选择新增的「Muse」配色后启用中性皮肤，不改其他配色。
- Muse 选项位于设置 → 外观与网站 → 外观 → 更多配色。沿用 `fire:site-palette` 的本地与 Cookie 持久化；默认仍为中性灰，不迁移或覆盖已有选择。自选主题色仍保留，其他配色切回即恢复；Muse 使用原蓝色，不混入自选强调色。
- 后台皮肤限定 `html[data-palette="muse"] body:has([data-capsule-scope="non-home"])`，覆盖顶栏、侧栏、卡片、表单、设置详情、通行密钥弹层、助手、附件和请求日志的中性色。首页独立工具样式、财务涨跌色、图表分类色、Dock 选中颜色与布局不改。
- 字体、字重和深浅模式仍由网站自己的持久化设置控制；动态的阅读层级按本表限定。
- 动态标题不再被工作区通用 h2 规则放大；动态输入与关闭按钮仅在本页覆盖全局输入/胶囊规则。
- `tests/feed-style.cjs` 校验取色表与作用域；浏览器另核对真实级联结果、手机/平板/桌面布局、弹窗和切页后的背景恢复。
- 样式由根布局静态引入，不再依赖动态导入/缓存视图决定 CSS 生命周期；刷新、HMR、返回已缓存页面都保留同一个样式入口。小人按钮有内联尺寸上限，图片与视频同框绝对定位；视频同时保留宽高属性，样式网络失败也不会按 480px 原尺寸撑开页面。
- 开发环境不注册生产 PWA worker，并仅注销本站 `/sw.js` 的旧注册，避免恢复旧开发 HTML/CSS；不清除用户偏好或其他 worker。生产 PWA 安装逻辑不变。
- 编辑入口只在右上角。正文不再重复编辑按钮或展示假新闻式引导卡；编辑弹窗包含内置模板、关注范围、自动更新与取消/保存，新闻模板保留指示文本及计数，更新状态收进小人任务详情。静默读取不会把旧动态换成骨架或错误横幅。
- 权限、指示 revision、历史内容及旧 App 请求字段不变；搜索能力的扩展和静默同步详见 `docs/feed-api.md`。

- 分组未选和新增加号统一1px虚线边框，选中项保留实心胶囊；正文底部不显示发稿日期，来源选项保留日期。首屏10条，底部“查看更早动态”每次追加10条。

- 「名人原帖」沿用信息流的字号、边界和深浅色变量：头像与真实人物身份、原帖北京时间、完整正文、大图、原文链接和翻译切换。人物筛选使用 URL，已读时间按组和人物保存到个人偏好；首次进入建立阅读基线，不将全部历史误标为新帖。

- 人物筛选改为横向头像列（64px圆形头像，名称在下），选中使用徽标同色细圆环与名字，头像右下角蓝点表示更新。手机维持横向滚动而不挤压名字。模板的人物头像与关注按钮并列，避免嵌套按钮；头像编辑使用原生文件选择及摄像机角标。粉色与蓝色平台徽标复用旧矢量且仅对白名单 ID 绘制，色彩在深浅主题保持平台原色。

- 人物选中圆环为 1px，颜色与白名单徽标同源；全部动态使用 38px 风车和柔和灰蓝色，深色模式提亮。人物勾选为 18px 空心圆环加小对勾。
- 人物切换期间，已读数据归属与 URL 筛选不一致时显示骨架；空态与分页入口只在对应人物读取完成后出现。

- 原帖头部仅显示人物、白名单徽标、账号与时间，完整北京时间通过时间元素 title 保留；账号过长省略且不挤出容器。链接/切换按钮至少40px高，互动按钮44px，头像筛选使用徽标同色键盘焦点环。

## 小人个人面板（2026-10-02）

动态入口小人下方增加中性细边名称胶囊，默认 Alcor；使用服务端账号快照，切换组首屏继续沿用同一名称和形象。个人面板参考用户给出的 Rocky 页面：左右圆形关闭/链接按钮、居中大头像、右下编辑笔、名称与绿色连接状态、五个图标胶囊页签和按日期分组的真实任务记录。编辑笔打开圆角半透明菜单，仅含「更换虚拟形象」「编辑名称」。不复制参考图中的示例任务，不添加信息流提示。

复用 body portal 的 AppModal，手机顶部留72px、桌面88px；手机顶部圆形操作保持同一行，面板内滚动。头像与上传预览保留明确尺寸及本地图标兜底，默认形象和上传图片可切换。新颜色的深色变量放在 `app/globals.css`，其余使用原有 feed 主题变量；同一小人资料不会改动特朗普/段永平的白名单头像和徽标。
