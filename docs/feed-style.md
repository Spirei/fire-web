桌面实测：页标题 34px / 40px / 600；动态标题 18px / 26px / 500；正文 16px / 22px / 400；时间 13px / 18px；正文最大宽度 768px；左侧图标 40px、间距 12px。指示弹窗 512px，标题 18px / 26px / 600，说明 16px / 22px，输入 14px / 20px，次操作与主操作均为 36px 高胶囊。手机输入仍为 16px，保留触控命中范围、平板弹窗和短屏适配。

字体使用系统无衬线与中文回退；不下载或分发 Muse 的专有 Optimistic 字体，因此拉丁字形不声称逐像素相同。小人沿用已本地化的原始循环视频，按用户要求放在动态页上方居中。

## 作用域与防回归

- 颜色在 `.feed-theme` 内定义，四类动态弹窗显式携带该类；body portal 不丢失配色。
- 只有 `.tab-panel:not([hidden]) .alcor-feed` 可改变工作区背景。缓存的隐藏动态页不能影响其他页。
- 动态页固定使用这组取色；其余后台仅在用户选择新增的「Muse」配色后启用中性皮肤，不改其他配色。
- Muse 选项位于设置 → 外观与网站 → 外观 → 更多配色。沿用 `fire:site-palette` 的本地与 Cookie 持久化；默认仍为中性灰，不迁移或覆盖已有选择。自选主题色仍保留，其他配色切回即恢复；Muse 使用原蓝色，不混入自选强调色。
- 后台皮肤限定 `html[data-palette="muse"] body:has([data-capsule-scope="non-home"])`，覆盖顶栏、侧栏、卡片、表单、设置详情、通行密钥弹层、助手、附件和请求日志的中性色。首页独立工具样式、财务涨跌色、图表分类色、Dock 选中颜色与布局不改。
- 字体、字重和深浅模式仍由网站自己的持久化设置控制；动态的阅读层级按本表限定。
- 动态标题不再被工作区通用 h2 规则放大；动态输入与关闭按钮仅在本页覆盖全局输入/胶囊规则。
- `tests/feed-style.cjs` 校验取色表与作用域；浏览器另核对真实级联结果、手机/平板/桌面布局、弹窗和切页后的背景恢复。
- 只改变展示，不改 feed API、权限、任务、来源或用户数据。
