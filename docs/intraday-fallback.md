# 个股分时读取 · 2026-10-13

用户确认顺序：富途 → 腾讯 → 东方财富 → Yahoo，按市场能力跳过不支持的源。Web和App v1/v2使用同一个 `fetchIntraday`，不在iOS复制外部接口或放宽API授权。

本轮线上只读复现：AAPU v1/v2分时45秒未返回，AAPU迷你分时与港股00700分时20秒未返回；相同服务器的AAPU历史日线约1.84秒返回320根，空分时请求约0.10秒正常，健康检查显示OpenD可用。因此不能靠增加App等待时间或修改价格卡片解决。原美股分时跳过腾讯，直接调用单Yahoo主机；此路径也没有富途RT_DATA与东方财富回退。隔离测试能复现忽略取消的源／响应体长期占住共享请求。线上无服务器日志，本轮不将这一模拟阻塞点称为已证明的唯一现场根因。

## 实现与边界

- 富途US／HK／CN分时使用原单连接队列的RT_DATA，关闭脚本推送，US Session.ALL后保留现有04:00–20:00单日合同；逐证券失败隔离，拒绝is_blank、错证券、无效价格、未来日期及空白伪造点。来源以真实返回日期为准，旧日数据标stale继续寻找更新源，不用实时快照拼走势。
- 腾讯按市场规范代码及已有chartApiUrl读取；东方财富只对能核实实际证券代码的US／HK／CN读取，采用每分钟收盘列，不能取开盘价；JP／KR沿腾讯、Yahoo，未知市场不猜secid。
- 单源富途3.5秒、其他2.5秒，整批14秒；独立调用等待覆盖代理准备、响应头和有界正文，即使上游忽略abort也可转后备。Yahoo query2延后200ms，仅在前三源未获得新有效分时后启用。快速源立即结束低优先级读取，不平行抢OpenD连接。
- 共享池每证券完成就发布，保护调用者ID及来源设置隔离；OpenD恢复改变缓存身份，不继续复用尚未过期的腾讯等后备图；端口持续可用但此前RT_DATA失败时也会优先重读富途，后备缓存不能挡住恢复。不可用端口在下一次读取最多使用1秒探测缓存。取消／期限过后不发布结果，全源失败明确错误，后续实际重试可恢复，不生成零价或假曲线。
- 不修改持仓、订单、现金、当日盈亏或历史日K来源。新字段source为兼容可选元数据，不改App v1/v2信封。

富途字段与订阅策略参照[官方RT_DATA文档](https://openapi.futunn.com/futu-api-doc/en/quote/get-rt.html)和[订阅文档](https://openapi.futunn.com/futu-api-doc/en/quote/sub.html)。OpenD端口可用不等于对应证券RT_DATA权限可用，拒绝／额度不足沿正常后备。
