# Liquid Glass 视频参考

`0920.mp4` 曾用于全站按钮的点击透镜参考。现按设计收敛：Liquid Glass 配色保留胶囊的静态通透材质，不再安装全站点击/长按浮层；头像、普通按钮、卡片、窗口与侧栏不受玻璃材质影响。车型展示台的 `LiquidGlassControl` 是独立的胶囊切换控件，保留自身交互。

参考用户本地 `LIQUID GLASS.mp4`：1206 × 382、60 fps、10.302 秒。按每秒及连续 100ms 抽帧观察，采用清透胶囊轨道、静止灰色选中底、按压鼓起、连续跟手透镜和释放吸附的结构。

`LiquidGlassControl` 共用于模式与六色线框。持续按住 320ms 后鼓起，单个 requestAnimationFrame 更新临界阻尼弹簧，驱动位置、形变与内容反向偏移；拖动不触发 React 重绘、不反复重启 CSS 过渡，静止停止刷新。松手提交最近选项；激活前移动超过 8px 或移出后释放取消选择。内容副本 inert / aria-hidden，键盘通过真实按钮选择。

44px 内容高度，4px 内距；完全鼓起时宽度增加 16%、高度增加 30%、内容放大 16%，速度最多增加 8% 横向拉伸。透镜下原字隐藏，避免双层重影；单次 1.6px 边缘位移与细边高光替代整片 RGB 分离和灰色背景滤镜。位移图只在尺寸改变时生成；色珠保持原六色。

`styles/liquid-glass.css` 放在配色样式之后，只给胶囊设置通透材质。其他配色和非胶囊面板保持普通材质。减少动态效果时关闭胶囊切换控件的形变和过渡。

这是 CSS / SVG 浏览器近似实现，内容放大与边缘位移作用于副本，但没有 Apple 原生合成器对任意背景的完整光学折射，不能称为逐像素一致。

本轮按 60fps 提取参考帧。`node tests/liquid-glass.cjs` 覆盖 600 个坐标帧、30–240Hz 弹簧一致性、拖动零状态重绘、长按阈值、提交、取消、多指及减少动态效果。浏览器通过开发期测试页按钮，执行两版相同的 4.2 秒合成指针轨迹，采集全部 253 帧；帧间隔中位数 16.7ms、P95 17.6ms，包含双控件和快照开销，不是独立性能基准。完整逐帧 HTML 作为交付附件，测试页不发布。
