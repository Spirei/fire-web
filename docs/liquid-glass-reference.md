# Liquid Glass 视频参考

参考用户本地 `LIQUID GLASS.mp4`：1206 × 382、60 fps、10.302 秒。按每秒及连续 100ms 抽帧观察，采用清透胶囊轨道、静止灰色选中底、按压鼓起、连续跟手透镜和释放吸附的结构。

`LiquidGlassControl` 共用于模型展示的三种显示模式及六色线框。真实按钮只渲染一套可访问交互；透镜里的内容副本为 inert / aria-hidden，不会重复进入键盘或读屏顺序。显示模式与模型渲染仍沿用现有回调。

视觉参数按当前控件尺寸换算：44px 内容高度，4px 轨道内距；按住时横向放大 1.14、纵向 1.34，释放后 320ms 吸附。透明中心外约 32% 半径范围生成圆角位移图，RGB 分别以 9/7/5px 位移形成细微色散；位移图只在尺寸改变时重建，拖动不重绘位图。色珠保持原六色，不经全站配色替换。

`styles/liquid-glass.css` 放在配色样式之后，统一首页、车型导入、模型面板和设置的玻璃表面：更低雾化、细白边、轻阴影；深色提高底色覆盖以保证阅读。非 Liquid Glass 配色保留普通材质。减少动态效果时关闭形变和过渡。

这是基于 CSS / SVG 的浏览器近似实现，不是 Apple 原生合成器，也不能视为逐像素一致的验证结论。真实背景折射取决于浏览器对 SVG backdrop-filter 的支持；不支持时仍保留内容透镜放大、透明层和边缘高光。不同画布内容、尺寸与浏览器会影响观感。

验证：`node tests/liquid-glass.cjs` 覆盖位移图对称、窄色珠、透明中心、真实组件指针回调的拖动提交、边界、多指拒绝和取消。浏览器另外验证模式拖动与换色。
