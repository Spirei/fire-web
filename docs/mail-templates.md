# 邮件模板

管理员在设置 → 数据与系统 → 邮件模板编辑修改邮箱验证码、找回密码、邮箱验证和邮件服务测试四种模板。每种文案独立保存；真实发信与预览共用服务端渲染器。预览只用模拟邮箱和验证码，不发送邮件、不创建凭证。

品牌横幅使用浅黄至青绿配色。最新保存的 `siteLogo` 和 `logoText` 每次从当前站点配置读取，Logo保留原比例，更新无需重启；相同图片路径被替换时也会按文件版本更新。发信将当时的图片嵌入CID，已发送邮件保留当时的品牌。预览读取同一图片快照，App可通过 `/api/system-assets/mail-banner` 取得当前横幅。图片不会从任意外部URL获取。

尺寸切换位于左侧、模板选择位于右侧。手机模式在桌面上使用较紧凑弹窗；桌面模式按640px邮件布局展开。空间不足时编辑区与预览上下排列，桌面邮件等比缩放到可用空间；窄屏没有横向溢出。设置分类标题缩小，详情打开时隐藏背景分类标题。

邮箱六位验证码30分钟有效，验证成功后的提交修改凭证5分钟有效且成功提交后立即失效。邮箱确认继续使用原有30分钟链接合同。

验证记录：

- 临时数据库覆盖模板权限、来源、文本转义、预览无副作用、四种实际发信渲染与CID、30分钟验证码和5分钟凭证、更新/替换Logo后的SMTP与预览联动。
- Chrome实际页面验证手机/桌面按钮与控件顺序；手机390×844及平板768×1024均无弹窗或画布横向溢出。390宽度下桌面邮件仍按640px排版，预览缩放至约288px；平板缩放至约598px。恢复正常浏览器视口后，手机/桌面弹窗分别约880px/1140px，并按窗口可用空间收敛。
- 没有发送真实测试邮件、修改真实账户身份或部署生产。实体手机和各邮件客户端的实机渲染尚未覆盖。
