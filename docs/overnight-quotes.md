# 美股夜盘报价 · Web / App 交接

v1/v2 `POST /quotes` 共用行情服务，响应仍为 `data.quotes[请求id]`，不更改身份、版本、持仓或盈亏归档周期。

## 实际数据与客户端解析

2026-10-02 线上匿名抽查 AAPL、NVDA、TSLA、TQQQ、TSLL、VOO、QQQ、BRK.B 均返回富途 `session:OVERNIGHT`。时间例如 `2026-10-01 23:36:54.780`，是来源的美东日期/时间，包含毫秒；v1/v2 格式一致。该价格的日期不能按中国日期或下一交易日字符串直接匹配。

无时区的美股时间按 `America/New_York` 解析，支持秒和可选1–9位小数秒；带时区的 ISO 字符串按其偏移解析。美东20:00开始的夜盘归入下一盈亏交易日期，跨午夜仍为同一夜盘周期。客户端缺少毫秒格式解析会把真实报价当成没有有效时间；不要为了适配客户端改写来源时间或给旧价补当前时间。iOS已确认修复解析器，并在使用真实线上信封验证生产解码与今日计算。

## 后端边界

- 富途只使用实际 `overnight_price` 和 `overnight_change_val`，且来源时间须在服务端请求的同一夜盘周期内，才标记 `OVERNIGHT`。`prevClose = price - overnight_change_val`，涨跌幅按同一基准计算；0涨跌仍为合法报价。缺少夜盘价/涨跌基准、无效时间或旧周期字段时保留来源常规报价及原时间，`session:REGULAR`，不借旧 `prev_close_price` 计算夜盘收益。
- 有效富途夜盘不被 Yahoo 图表覆盖，不因0成交/0涨跌被常规“幽灵报价”清洗删除。不支持的代码仍沿用整批快照剔除/二分容错，不影响其他标的。
- 当前 Yahoo 图表链路读取盘前/盘后覆盖，不提供可确认的独立夜盘流；20:00末根盘后点不能标成夜盘。常规价只使用与其配对的来源 `regularMarketTime`，不能借用任何其他分钟价的时间或本次读取时间；未知时间留空。
- 时钟按星期日20:00至星期五20:00区分本周交易周期：周日晚开始夜盘，周五20:00起结算，周六休市。时钟只是预期时段，节假日、停牌、权限和实际可用性仍由年度安排与真实报价判断，不把时钟标签当作实时开市证据。

官方字段与时区依据：[富途获取快照](https://openapi.futunn.com/futu-api-doc/quote/get-market-snapshot.html)；星期边界依据：[富途夜盘时段](https://www.futunn.com/learn/detail-5x24-hours-the-us-stock-trading-night-market-is-uninterrupted-78889-230334138)。API不新增“全市场夜盘必有价”的能力承诺；个股夜盘支持与成交可能不同。

## 缺报价口径

持仓继续保留在原列表。缺少可确认的当期夜盘报价时，本期金额显示 `—`；原常规价只可作为旧估值，不算当前夜盘收益，也不将缺价填成0、隐藏股票或移到另一列表。`REGULAR` 即使在夜盘请求时返回，也不能被客户端重新标记为夜盘。

## 验证范围

`tests/overnight-quotes.cjs` 使用模拟 SDK、模拟网络与受控时间，覆盖毫秒原样保留、跨午夜/跨年/夏令时、星期边界、旧周期/缺字段降级、正确基准与0涨跌、OTC容错与别名、富途优先、Yahoo20:00与常规时间防伪；不连接 OpenD、不调用真实账户。线上抽查是修复前事实，代码推送不等于部署。部署后需与实际 App 持仓及用户授权的真实会话再次验证。
