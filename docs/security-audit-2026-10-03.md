# Alcor Web 安全审计 · 2026-10-03

本次审查 Web 源码、252 个 API 路由及共享实现、身份验证与账号授权、上传和文件清理、浏览器渲染与离线存储、外部采集、凭据配置、备份及独立模型优化工具。已确认的问题均在本地修复，并加入隔离回归；没有修改真实账号或财务记录。

这是源码与本机验证结果，未对生产服务器执行侵入测试，也不代表不存在其他漏洞。高/中风险为基于触发条件与影响的审计分级，并非 CVSS 评分。修复是否在线上生效，以后续发布的代码与运行实例为准。

## 防御性加固与性能优化

- OCR、订单和简化账本 multipart 上限贴合文件业务限制及少量表单余量；无 Content-Length 的请求同样受限。
- 视觉服务与容器更新禁用带凭据的自动跳转；上游 JSON 设实际响应限额，声明超限也主动取消流，避免连接残留。
- IPv4 映射 IPv6、链路本地 IPv6 和尾点主机名正确识别，私网出站继续绕过代理；已有 RSS DNS 固定与逐跳安全规则保持不变。
- 备份间隔和保留数读写均归一化，避免小数舍入为零；同进程并发复用在途快照，同秒目录独占创建，失败清理未完成目录并释放锁，延迟自动任务重新检查开关。自动备份关闭时仍允许显式手动备份。
