## 测量方法

在六条边线的局部条带内寻找亮芯，排除红色标注框、界面文字和黑色背景，正交最小二乘拟合 Ax + By + C = 0。颜色取有效亮芯 RGB 中位数。独立 origin / angle 重建各自拟合线，referenceAspect = 541/377 保持归一化空间比例。

## 速度与车轮

视频约 14.25 秒起步，以 0.25 秒间隔读到 67、138、164、200、244、268、280、300、310、318、324、328、331、333、335、336 km/h。起步时刻受采样网格影响，加速响应按每秒 1.05 拟合、最高 340 km/h；这组采样的均方根差为 8.4 km/h。松手后 263 → 174 → 116 的下降按每秒 1.65 拟合。这是曲线拟合，不宣称逐帧遥测完全相同。

角速度 = 显示车速 ÷ 3.6 ÷ 实测外胎半径。转向按模型车轴转换后的方向确定，同一只轮的轮圈、胎面、侧壁共用外胎半径。高速额外 mip 过滤压低字样闪烁，低速恢复清晰；这不等于摄影机快门模糊的逐像素重建。

Object_10 和 Object_27 各含一对轮胎，只有横向需要拆分。前后轮父节点已有不同的纵向平移，禁止拿别的网格中线切它们。Object_5 / 7 / 14 / 25 共用 wheels_mat，但不满足完整圆轮截面，保留原网格。拆分保留全部原三角面、绕序和顶点属性，任意转角下轮心固定。

## 分段、遮挡与开销

四黄、两蓝全部按速度积分推进虚线相位，保留明确间隙；两侧上方浅灰细线使用独立错相与渐隐尾迹。角宽使用屏幕导数抗锯齿，避免左下细蓝线在低分辨率下漏采样。

旧车体包围矩形把车旁空白也当作车，导致左侧线条被整块截断。现在复用主场景深度，仅车体实际表面遮线，路面和车旁空白可见；不增加一遍车体蒙版绘制。深度在后期交换缓冲中保留，最终屏幕合成读取当帧深度。

高速倒影强度归零后跳过镜像场景绘制，减速恢复倒影前重新更新；销毁展示台时一并释放后期双缓冲。以上属于减少无效绘制和补全资源释放，未声明固定帧率增幅。
