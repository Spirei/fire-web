# 全站排查与修复 · 2026-09-26

## 范围

本轮覆盖前后端共享读取、缓存、首帧状态、身份认证、用户资料、上传下载、分页及构建部署检查。扫描 148 个 API 路由与共享库；写入回归仅在临时 SQLite 数据库及上传目录运行，不改真实账户资产或站点配置。

## 已修复

| 问题 | 修复位置与处理 |
| --- | --- |
| Bearer 认证和 Cookie 会话混用导致退出或保留会话错误 | `lib/auth.ts` 与退出、密码、TOTP 路由统一令牌选择；Cookie 退出验证请求来源 |
| 管理员可设置重复邮箱 | `lib/auth.ts` 按不区分大小写检查其他用户邮箱 |
| 手动更新汇率后其他已挂载视图继续使用旧值 | `lib/useRates.ts`、相关 views 与 `FxConverter.tsx` 同步刷新事件；普通读取仍不调用外部汇率源 |
| 非法汇率缓存及过期异步响应 | `lib/ratesCache.ts` 过滤非有限或非正数；共享 hook 与持仓使用请求序号，卸载后不回写 |
| FIRE 把进入页面时间当成汇率更新时间 | 展示接口真实更新时间，无时间时标为参考汇率 |
| FIRE 空白年数被转换为 0、误显示已达成 | 空白/非有限值显示占位；自动达成条件撤销时清除旧推导值 |
| 中文偏好 Cookie 编码后超出浏览器上限 | `lib/prefsCookie.ts` 按 URI 编码后的实际长度限额 |
| 无效文件 Range 回退整文件下载 | 上传文件路由返回 416，并保留合法后缀及分段下载 |
| 周期 K 线首次与缓存命中的条数不同 | 缓存实际返回的切片；日 K 和周期 K 隔离指数标识 |
| 完整 K 线重复并发与缓存无限增长 | 合并同键请求、失败释放、清理过期缓存、最多 128 项；请求代码限长与条数取整 |
| 附件分页 Infinity/异常偏移导致 SQL 错误 | `lib/attachments.ts` 校验安全整数并限制偏移 |
| 遗留辅助测试夹具缺变量 | 补齐工作台保存测试的 mode/onSaved，不改变生产工作台逻辑 |
| 无障碍树残留调试文字 | 删除全球经济标题旁的 dbg |

- 本轮修复已发现且可复现的问题，不宣称穷尽所有潜在问题或完成渗透测试。

- 不修改生产数据，不重置用户密码，不部署线上服务。运行时 data 缓存不纳入提交。
- 3D 生产代码与卡面动画此次没有改动，相关自动化通过不代表逐台实体设备视觉验收。
