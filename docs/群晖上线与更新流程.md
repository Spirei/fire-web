# Fire 股票记实网站：群晖上线与更新流程

> GitHub：`https://github.com/your-github-name/fire-web`
>
> 群晖目录：`/volume1/docker/fire`
>
> 网站地址：`http://群晖IP:3000`

## 一、整体流程

```text
本地修改 → git push → GitHub Actions 构建 linux/amd64 镜像
→ GHCR ghcr.io/your-github-name/fire-web:latest
→ 群晖 pull → compose up 重新创建容器
```

## 二、本地电脑

在本地 `fire-web` 项目根目录执行：

每次修改后：

```bash
npx tsc --noEmit
git add .
git commit -m "说明本次修改"
git push origin main
```

等待 GitHub Actions 中的 TypeScript 检查和 amd64 镜像发布均显示 **success**。

本地 Git 代理（可选，请换成自己的代理地址）：

```bash
git config --local http.proxy http://proxy-host:8080
git config --local https.proxy http://proxy-host:8080
```

不要提交 `.env`、`.env.local`、`data/`、`.next/`、`node_modules/`、`dist/`、用户头像和报告。

## 三、群晖一次性配置

群晖目录：`/volume1/docker/fire`

将项目根目录的 `docker-compose.ghcr.yml` 复制为：

```text
/volume1/docker/fire/docker-compose.ghcr.yml
```

创建 `/volume1/docker/fire/.env`，至少包含：

```dotenv
GHCR_IMAGE=ghcr.io/your-github-name/fire-web
IMAGE_TAG=latest
HOST_PORT=3000
```

保留原有管理员密码、代理和 API Key，不要把 `.env` 提交到 GitHub。

登录私有 GHCR（只需一次）：

```bash
docker login ghcr.io
```

用户名填自己的 GitHub 用户名，密码填 GitHub Personal Access Token (classic)，Token 至少勾选 `read:packages`。

确保目录存在：

```bash
mkdir -p /volume1/docker/fire/data
mkdir -p /volume1/docker/fire/uploads
```

## 四、群晖日常更新

等待 GitHub Actions 成功后，在群晖执行：

```bash
cd /volume1/docker/fire
docker compose -f docker-compose.ghcr.yml pull
docker compose -f docker-compose.ghcr.yml up -d --force-recreate
docker compose -f docker-compose.ghcr.yml ps
```

网站地址：`http://群晖IP:3000`

查看日志：

```bash
docker compose -f docker-compose.ghcr.yml logs --tail=100 fire
```

## 五、回滚

每次 Actions 也会生成短 SHA 标签，例如 `abc1234`：

```bash
cd /volume1/docker/fire
IMAGE_TAG=abc1234 docker compose -f docker-compose.ghcr.yml up -d --force-recreate
```

恢复最新版本：

```bash
docker compose -f docker-compose.ghcr.yml pull
docker compose -f docker-compose.ghcr.yml up -d --force-recreate
```

不要删除 `/volume1/docker/fire/data` 或 `/volume1/docker/fire/uploads`，不要执行 `docker compose down -v`。

## 六、常见错误

- `no such file or directory`：Compose 文件没有放到 `/volume1/docker/fire/`。
- `pull access denied`：重新执行 `docker login ghcr.io`。
- 拉到旧镜像：确认 Actions 成功后重新执行 `pull` 和 `up -d --force-recreate`。

## 七、最简清单

本地：修改 → `git add .` → `git commit` → `git push` → 等 Actions 成功。  
群晖：`pull` → `up -d --force-recreate`。
