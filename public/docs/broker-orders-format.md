# 券商成交订单导入格式

选择原始 `.xlsx` 文件（最大 16 MiB）。数据工作表表头的 A 列为「订单状态」，文本使用 OOXML 内联字符串，数字可用数值单元格。先预览，核对每笔结果后确认导入。

| 字段 | 填写要求 |
| --- | --- |
| 订单状态、方向 | 已成交的买入或卖出 |
| 市场、股票代码 | 与本人券商账户下已登记的证券一致 |
| 成交数量、成交均价、币种 | 正数和证券原币。若有成交金额，须与数量乘均价一致 |
| 委托时间 | 带明确时区，例如 `2026-01-15 10:30:00 ET`，或使用含 UTC 偏移的 ISO 时间 |
| 费用（或手续费） | 填写已核实的实际费用，零费用需明确填写 0 |
| 结算币种、实际结算净额 | 港股通成交须提供原件记载的人民币净结算额 |

预览会列出可导入、重复、非已成交和待核对的行，并说明阻止导入的原因。同一证券组存在待核对行时，系统保留该组原件供核对。确认后按回执显示实导笔数及分组结果。
