# Fire 本地模型工具

双击 **启动模型工具.command** → 选择原始 GLB（可多选）→ 选择导出目录。使用 Mac 原生文件窗口，不启动本地网站、不监听端口，也不上传数据。

首次需要 Node.js 22+ 和网络：自动安装本工具独立依赖，处理大模型时下载经 SHA-256 校验的 KTX 编码器。之后复用本机缓存。所有依赖都在本地，网站构建和 Docker 镜像不包含本目录。

每个模型导出独立文件夹：

- `*-optimized.glb`：导入网站的高清模型。达到 50 MiB 文件或 256 MiB 贴图展开阈值时使用 UASTC；保留几何与贴图尺寸。未达到条件则直接复制原文件。
- `*-preview.glb`：1K 首页轻量预览，保存车型后，在该车型卡片点击“上传首页预览”。不要把它当高清车型导入。
- `report.json`、校验清单和 `上传说明.txt`：检测结果与使用说明，不需要上传网站。

原始文件不修改，已有导出文件不覆盖。UASTC 是高质量有损，不是逐像素无损；主要降低 GPU 贴图内存，下载文件不一定更小。请保留原始 GLB，以后都从原始文件导出，避免重复有损压缩。GPU 压缩过的输入会明确拒绝。

关闭处理终端会中断任务；未完成的隐藏临时目录可以删除。重新运行会创建新导出目录，不影响已完成的结果。多文件逐个处理，某个失败会继续其他文件，并报告失败数量。

命令行：

```sh
npm ci
node app.mjs --input /绝对路径/car.glb --output /绝对路径/导出目录
npm test
```

手动上传不会覆盖现有车型：先按正常导入流程创建并确认新车型，再按需要隐藏/移除旧车型。网站只保留 KTX2/Meshopt 读取能力和普通文件上传，不执行编码。
