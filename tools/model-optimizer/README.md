# Fire 本地模型工具 · Mac / Windows 通用

只有一套程序、一套浏览器界面。它仅监听本机 `127.0.0.1`，文件不会上传到网站或第三方；压缩在独立本地进程运行。

## 启动

安装 **Node.js 22+**，进入本目录，在 macOS 终端或 Windows 命令提示符运行：

```sh
npm start
```

工具自动打开浏览器。首次自动安装本机依赖，以后复用；换操作系统/CPU/Node 版本会重新准备对应依赖，避免把 Mac 的二进制带到 Windows。若浏览器没有自动打开，复制终端显示的本地网址即可。

Windows x64/ARM64 首次处理大模型时，会下载并校验官方 KTX 4.4.2 安装包，打开安装向导；请允许系统授权，使用默认安装目录。Mac 编码器自动安装到用户缓存。初次准备需要联网，之后可复用本机依赖和编码器。Windows 若组织策略禁止安装，需要管理员先配置 KTX 4.4+ 的 PATH。

## 使用

1. 选择或拖入原始 GLB，支持多选，每个最多 512 MiB，最多排队 8 个。
2. 文件逐个处理，页面实时显示状态；刷新页面可继续查看本次任务。
3. 在网站 `/showcase/import` 选择**同一份原始 GLB**，完成体检、调校并保存车型；网站上限是 250 MiB。
4. 下载 **首页预览**，在对应车型卡片点击“上传首页预览”（≤ 32 MiB）。不要把 1K 预览当作高清主模型导入。
5. 若报告显示生成了 UASTC 压缩版，下载 **高清优化版**，在同一卡片点击“上传移动端原画”（≤ 96 MiB）；未达到压缩阈值时工具会复制原文件，不必再传这个副本。副本必须与网站保存的原件来自同一源文件，网格和贴图尺寸一致。

结果同时保存在本目录的 `output` 文件夹，包含 GLB、指纹清单、报告和上传说明；原文件不改动。关闭启动终端可退出，未完成任务将中断；再次启动后可从 output 取回已经完成的导出。失败或中断留下的 `.fire-export-*` 临时目录可在停止工具后删除。

文件 ≥50 MiB 或贴图展开 ≥256 MiB 时生成保留源尺寸和几何的 UASTC 高清版，否则复制原文件。UASTC 是高质量有损，不是逐像素无损，主要降低 GPU 贴图内存，下载文件不一定更小。每次请从原始 GLB 开始，已 GPU 压缩的输入会拒绝，以免重复有损压缩。

## 外置贴图素材（AMR26 涂装包）

网站导入工作台只接受自包含的 GLB。已核对的 Sketchfab「2026 Aston Martin AMR26」下载包以 Haas VF-26 几何为底稿：`source/2026_haas_vf-26.glb` 内嵌的是 1K Haas 车身图，`textures/` 另带 Aston Martin 的 4K 车身图、2K 贴花与轮毂图。先将四张图按材质名称打包，再运行本工具；不要直接把外置贴图文件夹上传到网站。

```sh
node scripts/repack-sketchfab-textures.mjs /路径/source/2026_haas_vf-26.glb /路径/textures /路径/2026-aston-martin-amr26-livery.glb
```

此脚本仅接受已核对的底稿来源，不会修改下载的原文件；输出单文件 GLB 后，在本地网页选择它即可。脚本保留原作者与底稿来源元数据。该车型的高分辨率贴图在 GPU 展开后约占 303 MiB，移动端仍须实机验证高画质承载能力。

## 分发与网站

把整个 `model-optimizer` 目录给另一台电脑即可，**不要携带 node_modules 和 output**。没有分开的 Mac/Windows 前端，也不需要安装网站项目。本目录已排除在网站 Docker 构建之外；网站只保留文件上传和 KTX2/Meshopt 显示能力，不运行编码器。

命令行批处理仍可使用 `node app.mjs --input /路径/car.glb --output /路径/导出目录`。运行测试：`npm test`。

已验证本机浏览器端导出、下载、队列和跨平台路径处理；Windows 安装向导尚需 Windows 实机验证。
